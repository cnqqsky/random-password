# 随机密码生成器

本地运行的随机密码生成网站，零依赖、单文件、可直接部署到 Cloudflare Pages。

## 功能

- 四类字符开关：小写 / 大写 / 数字 / 符号
- 「排除字符」：勾选后框内字符不会出现在密码中（默认排除易混字符 `iIl1o0O`）
- 实时显示「可用字符数」
- 密码长度 4–64（默认 17）、数量 1–50（默认 1）
- 基于熵值的密码强度评估（弱 / 中 / 强 / 极强）
- 复制单条 / 复制全部 / 下载 .txt
- 本页历史记录、明暗主题（记忆偏好）、响应式
- 使用 `crypto.getRandomValues` 密码学安全随机数，全部在浏览器本地计算，不上传服务器

## 本地预览

```bash
python -m http.server 8123
# 打开 http://localhost:8123/
```

## 部署

直接用 `wrangler pages deploy` 部署当前目录即可（`index.html` 为入口）。
